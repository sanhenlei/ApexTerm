# ApexTerm 改造:本地运维工作台(快捷命令库 + Markdown 笔记 + 右侧编辑器 + 文件面板位置设置)

## Context

wxl 的使用模式是"本地终端为主、偶尔 SSH",现有左侧栏(纯会话列表)不匹配需求。目标:左侧栏改为**会话 / 快捷命令 / 笔记**三区块,快捷命令与笔记改为**用户自选工作目录下的文件存储**(可放 iCloud Drive/网盘同步,换电脑可直接加载),右侧新增**编辑器窗格**(tabs 页签混排命令文件与笔记)。另:现有 SFTP 文件面板固定在下方,改为**可配置显示在上/下/左/右**。

本机无 Xcode,验证走 GitHub fork + Actions CI(仓库自带 `.github/workflows/ci.yml`)。

## 核心设计决策

**存储 = 文件系统,零数据库**:
```
<workdir>/                      # 默认 ~/Documents/AetherTerm,首启引导选择,可指向同步盘
  commands/<分组>/<标题>.sh      # 快捷命令:文件名=标题,内容=命令,子目录=分组
  notes/<分组>/<标题>.md         # 笔记:同上,Markdown 源文件
  sessions.json                 # 会话自动镜像导出(脱敏,凭据仍在各机 Keychain)
```
- 分组拖拽 = 文件移动;同步盘/Finder 里直接可见可管理;原子写 + 目录监听自动刷新
- Markdown 预览用 **MarkdownUI**(gonzalezreal/swift-markdown-ui,SPM 引入,项目首个第三方依赖)

**交互**:
- 命令**单击 = 仅输入**到当前 tab 焦点 pane(不带 `\n`,手动回车触发);**⌥单击 = 输入+回车**直接执行;双击/悬停铅笔/右键 = 在编辑器打开
- 笔记单击 = 右侧编辑器打开 tab
- `{{var}}` 模板变量保留(复用 `Snippet.resolvedCommand` 逻辑,泛化为字符串工具函数)

**布局组合**:SFTP 面板在终端区内排布(上/下/左/右),编辑器窗格在整个终端区右侧——两者独立组合,如 SFTP=左 + 编辑器=右 可同时成立。

## 明确不做(V1)
